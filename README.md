# 수호의 영어 DT 대모험

초등 1학년 수호의 영어학원 DT 시험 대비용 학습 웹앱 (갤럭시 탭 S7 + S펜에 맞춤).
**서비스 주소: https://suho-english-dt.vercel.app** (로그인·설치 필요 없음)

앱 코드는 `index.html`, 시험 내용은 `data/sets/*.json`(시험 하나 = 파일 하나)에 있어요. 빌드 과정 없이 Vercel 정적 사이트로 배포해요.

## 파일 구조
- `index.html` — 앱 화면·기능 (내용 없음)
- `data/sets/<세트id>.json` — 시험지 문장·단어 (여기만 고치면 됨)
- `tools/build_content.py` — 세트 파일 검사 후 `data/content.js`(앱이 읽는 파일)와 `standalone.html`(파일 하나짜리 오프라인용) 생성
- `CONTENT_GUIDE.md` — 새 시험 자료를 반영하는 순서와 세트 형식

## 새 시험 추가
1. `data/sets/` 에 세트 JSON 추가 (형식은 `CONTENT_GUIDE.md`)
2. `python3 tools/build_content.py` (오류 없을 때까지)
3. main 에 푸시 → 자동 배포. 앱은 새로 추가된 세트를 한 번 자동으로 열고, 홈의 '다른 시험 고르기'로 예전 시험도 다시 볼 수 있어요.
- 별·스티커는 전체 공통, 단어 암기 단계·틀린 단어는 시험별로 따로 저장돼요.

## 내용
- **DT 문장 연습** (2026-11 세트: DSB1 DT Preview): Do you like ~? / Can you play ~? / How much is it? / What did you eat? / What are you doing? — 5단원 26문제
  - 📖 듣고 배우기 · 🧩 단어 고르기 · ✏️ 펜으로 써보기 · 🏆 실전 DT 도전(랜덤 10문제 / 전체 26문제)
- **단어 암기** (DT REVIEW VOCAB LIST 27개): 9개씩 3묶음 + 전체
  - 🃏 카드 → 영어→한글 → 한글→영어 → 🔤 철자 맞추기 → ✏️ 펜으로 쓰기, ❗ 틀린 단어 다시
- **Lesson 9 단어 시험** (2026-11 세트: DSB1 Lesson9 The Silly Wishes, 20개 — 지금 앱이 기본으로 여는 시험): 문장 없이 단어만
  - 7 · 7 · 6 세 묶음 + 전체, 단어 암기 5단계는 위와 같음
- 펜 쓰기: 영어 4줄 노트, 따라쓰기 힌트, 펜 색 8가지(흰색 포함), 칠판/종이 배경, 부분 지우개, 되돌리기, 펜만 쓰기(손바닥 방지)
- 정답 확인: 정답을 내 글씨 위에 초록 테두리 글자로 겹쳐 보여줌
- 화면 크기 자동 맞춤 + －/＋ 직접 조절
- 별 ⭐ 10개마다 스티커, 기록은 기기 브라우저(localStorage)에 저장
- 발음: 브라우저 음성(TTS, en-US / ko-KR)

## 고친 것
- 단어만 있는 세트: 홈에서 '실전 DT 도전'(문장 문제) 숨김, 시험 고르기에 '🔤 단어만' 표시
- 단어 묶음이 9개씩 끊겨 마지막 묶음이 2개만 남던 문제 → 묶음 수는 그대로 두고 고르게 나눔 (20개 ➜ 7·7·6, 27개는 9·9·9 그대로)
- 펜으로 써보기 빈 화면: 버튼의 `write()`가 브라우저 내장 `document.write`로 실행되던 문제 → 함수 이름 `writeSent`로 변경

- 아이패드(크롬·사파리 모두 WebKit) + Apple Pencil: 손글씨 입력(Scribble)을 켜 두면 빠르게 이어 쓰는 획이 사라짐 → 쓰는 칸에서 touchstart/touchmove 기본 동작을 막아 우회 (WebKit bug 217430)
- 펜·손 터치 구분: 지금 쓰는 펜(pointerId)의 신호로만 획을 시작/끝냄. 손으로 쓰는 중 펜이 닿으면 손 자국을 지우고 펜으로 전환

- 아이패드 영어 읽기: 첫 터치 때 음성 잠금 해제, cancel 직후 speak 방지(150ms), 목소리 목록 늦게 오는 기기 대비 재탐색, 장난감 목소리 제외(Samantha 등 우선), 홈의 🔊 소리 점검
